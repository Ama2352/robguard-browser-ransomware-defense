## Demo 1 — Attack Flow

```
Browser → https://localhost:3000/
            │
            ▼
      main.html  loads→  js/fsa.js + js/encryption.js
            │
            ▼  (user clicks button, grants folder access)
            │
      fsa.js: for each file in folder
        1. entry.getFile()            read original bytes
        2. encryptFileBuffer()        AES-256-GCM encrypt
        3. entry.createWritable()     open the SAME original file for writing
        4. writable.write(encrypted)  overwrite in-place with ciphertext
        5. writable.close()           commit to disk  ← no hook, proceeds freely
            │
            ▼
      extortion.html  (ransom note: BTC address, countdown, victim ID)
      Original files still present by name — content is now unreadable ciphertext
```

## Demo 2 — RøBguard Defense Flow

```
Browser → https://localhost:3000/protected
            │
            ▼
  main_protected.html  loads→  js/robguard.js  ← HOOKS INSTALLED FIRST
                        loads→  js/fsa.js + js/encryption.js
            │
            ▼  (user clicks button, grants folder access)
            │
      fsa.js starts attack — robguard.js hooks intercept each step:

      ┌─ Hook: getFile ──────────────────────────────────────────────┐
      │  reads original file bytes                                    │
      │  stores: _robOrigEntropy, _robOrigSize                       │
      └──────────────────────────────────────────────────────────────┘
                │
      ┌─ Hook: createWritable ───────────────────────────────────────┐
      │  snapshots original entropy/size onto the new stream         │
      │  initialises _robChunks = []                                 │
      └──────────────────────────────────────────────────────────────┘
                │
      ┌─ Hook: write  ◄── KEY INTERCEPTION POINT ───────────────────┐
      │  1. extract bytes from write() argument                      │
      │  2. entropy_diff = entropy(bytes) − _robSnapOrigEntropy      │
      │     (~+3.5 for AES output on text files)                     │
      │  3. size_diff = bytes.length − _robSnapOrigSize              │
      │     (~+32 bytes from IV + padding)                           │
      │  4. POST /api/classify {entropy_diff, size_diff}             │
      │          │                                                   │
      │          ▼  server.js spawns:                                │
      │     classify.py entropy_diff size_diff                       │
      │          │  loads best_model.pkl + scaler.pkl                │
      │          │  → predict([entropy_diff, size_diff])             │
      │          ▼                                                   │
      │     label = 1  →  window._robBlocked = true                  │
      │                   redirect to /robguard_blocked.html         │
      │                   originalWrite() NOT called                 │
      │                   ← no encrypted bytes ever reach disk       │
      └──────────────────────────────────────────────────────────────┘
                │
      ┌─ Hook: close — guard only ───────────────────────────────────┐
      │  throws if _robBlocked, otherwise passes through             │
      └──────────────────────────────────────────────────────────────┘
                │
                ▼
      robguard_blocked.html
        shows: filename, entropy_diff, size_diff, model decision
        "Your files are safe."
```

## ML Classifier Pipeline

```
entropy_diff  ──┐
                ├──► scaler.transform()  ──►  best_model.predict()  ──►  0 or 1
size_diff     ──┘    (zero mean,                (KNN — selected by Stage 7
                      unit variance)             Recall=1.0000, Precision=0.9993)
```

**Actual CV results (from Colab run):**

| Model | Recall | Precision | F1 | Accuracy |
|-------|--------|-----------|-----|---------|
| **KNN** ✅ | **1.0000** | 0.9993 | 0.9996 | 0.9996 |
| XGBoost | 0.9996 | 0.9994 | 0.9995 | 0.9995 |
| Random Forest | 0.9995 | 0.9996 | 0.9995 | 0.9995 |
| Decision Tree | 0.9991 | 0.9996 | 0.9993 | 0.9993 |

KNN selected: only model with perfect Recall (1.0000) and highest Precision among those.

**Why entropy_diff discriminates ransomware:**

| File change | entropy_diff | size_diff |
|-------------|-------------|-----------|
| Benign text edit (add/remove words) | ≈ 0.00 | negative or small |
| AES encryption of a text file | **+3.0 to +4.0** | +16 to +32 bytes |
| AES encryption of a binary/zip file | **+0.03 to +0.5** | +16 to +32 bytes |

## Restore After Cloning

```bash
# 1. Install Node dependencies
cd RoB/backend && npm install

# 2. Create Python venv
cd ../..
python -m venv .venv
.venv/Scripts/pip install scikit-learn xgboost numpy

# 3. Generate SSL cert
cd RoB
openssl req -x509 -newkey rsa:2048 -nodes -days 365 \
  -keyout localhost.key -out localhost.crt -subj "/CN=localhost"

# 4. Generate demo victim files
cd ../../test_victim && python generate.py

# 5. Run Colab notebook → download best_model.pkl + scaler.pkl → place in models/

# 6. Start server
cd ../RoB/backend && node server.js
```
